## Twitch-Channel-Points-Auto-Highlight
A TamperMonkey script to automatically spend Channel Points and send highlighted messages on Twitch with Ctrl+Enter.

TamperMonkey browser extension: https://www.tampermonkey.net/

Install using url: https://raw.githubusercontent.com/TZFC/twitch-tampermonkey-highlight/main/twitch-auto-highlight.user.js

Or on Greasy Fork: https://greasyfork.org/scripts/593515-twitch-channel-points-auto-highlight
